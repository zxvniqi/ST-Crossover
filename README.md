# Crossover Episodes (크로스오버 에피소드)

여러 채팅의 캐릭터와 유저가 한 에피소드에서 만나는 외전을 써 주는 SillyTavern 확장입니다.
같은 캐릭터 A가 B채팅·C채팅에 있으면 **B의 A와 유저, C의 A와 유저**가 각자의 기억을 가진 채 한 장면에 등장합니다.

- 채팅 2~4개 선택 (1:1 채팅, 그룹 채팅 모두 가능)
- 채팅별 **페르소나 자동 감지**: 채팅 고정 → 마지막 메시지 → 캐릭터 연결 → 기본 페르소나 순서
- 채팅별 **요약 자동 불러오기**: 요약 확장이 꺼져 있어도 채팅 파일에서 바로 읽음
  - 코끼리를 생각하지마 · Memoria · 시나리오 자동요약 · 기본 Summarize · Qvink Memory
  - 그 밖의 요약 확장은 이름이 summary/memory 같은 데이터를 자동으로 찾아서 후보에 올림
- **다인봇 지원**: 로어북에 인물이 들어 있는 카드는 대화와 요약에 많이 나온 인물을 자동으로 골라 넣음 (직접 선택 가능)
- 같은 인물이 여러 세계에 나오면 `미카엘 (대전쟁AU)`처럼 세계별로 구분하고, **형광펜 색**도 다르게 표시
- 결과는 **현재 테마의 채팅 화면과 같은 모양**으로 표시 (마크다운, 따옴표 색, 글꼴)
- 모든 결과는 **보관함**에 저장되고, 검색·복사·편집·삭제 가능
- 다른 확장 없이 동작

## 설치

ST → 확장(퍼즐 아이콘) → **Install extension** → 이 저장소의 GitHub 주소를 붙여넣기

## 사용법

1. 마법봉 메뉴 → **크로스오버 에피소드**
2. 세계마다 캐릭터(또는 그룹) → 채팅을 고릅니다. 최신 채팅이 자동으로 선택돼요.
3. 같은 캐릭터를 여러 번 쓸 때는 **별칭**(예: 현대AU)을 붙이면 결과에서 구분하기 쉬워요.
4. 주제를 적고 **생성**을 누릅니다. **미리보기**로 모델에게 보낼 내용과 토큰 수를 먼저 볼 수 있어요.

슬래시 명령:

```
/crossover 두 사람이 같은 카페에서 마주친다
/crossover set="세트 2" 비 오는 날
```

### 형광펜

- 색은 캐릭터·페르소나 아바타에서 자동으로 뽑아요. 아바타가 없는 로어북 인물은 이름으로 색을 정해요.
- 색 칩을 누르면 색을 바꿀 수 있어요.
- 본문에 다른 표기로 나오는 이름(예: `カシアン` → `카시안`)은 **편집 · 이름**에서 추가하세요. 다음 에피소드에도 기억돼요.

## 세부 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| 분량 | 보통 | 짧게 ≈600단어 / 보통 ≈1,200 / 길게 ≈2,500 |
| 세계별 최근 메시지 | 20 | 요약 다음에 넣는 최근 대화 수 |
| 세계별 최대 글자 수 | 8000 | 세계 하나에 쓰는 예산 (카드 20% · 로어북 인물 25% · 세계 설정 10% · 페르소나 8% · 요약 25% · 나머지는 최근 대화) |
| 다인봇 자동 등장인물 수 | 4 | 로어북 인물을 자동으로 몇 명까지 넣을지 |
| 출력 언어 | Korean | |

## 저장 위치

- 설정·세트: `extensionSettings.crossover_episodes`
- 보관함: 브라우저 IndexedDB(localforage, `crossover_episodes_archive`). 기기마다 따로 저장돼요.
- 다른 채팅 파일은 **읽기만** 하고, 절대 수정하지 않아요.

## 문제 해결

- 설정 패널 → **디버그 로그**를 켜면 F12 콘솔에 `[Crossover]` 로그가 나와요.
- 세계 카드에 ⚠ 표시가 뜨면 그 채팅만 건너뛰고 나머지로 생성해요.
- 채팅을 방금 수정했다면 ⟳(다시 읽기) 버튼을 누르세요. 캐시는 2분 동안 유지돼요.

## 코드 구조

```
index.js            진입점 (마법봉 버튼, 설정 패널, /crossover)
src/sources.js      캐릭터·그룹·채팅 파일·로어북 읽기 (캐시)
src/persona.js      채팅별 페르소나 판별
src/summaries.js    요약 확장 어댑터 — 새 요약 확장 지원은 여기에 어댑터 하나만 추가
src/lore.js         다인봇 로어북 인물 선택
src/prompt.js       세계별 데이터 수집 + 프롬프트 조립 (모델이 읽는 문장은 영어)
src/runner.js       생성 흐름 (UI와 슬래시 명령이 함께 씀)
src/colors.js       아바타 대표색 추출
src/highlight.js    형광펜 표시와 범례
src/reading.js      테마 맞춤 읽기 화면 (messageFormatting + .mes_text 규칙 미러링)
src/episode-view.js 결과·보관함 공통 보기
src/ui.js           팝업 (새 에피소드 / 보관함)
src/archive.js      보관함 저장소
```

## 보안

이 확장은 브라우저에서 JavaScript로 동작하며 모든 채팅 기록을 읽을 수 있습니다. 데이터를 외부로 보내지 않고, 생성은 ST에 연결된 API로만 합니다.
