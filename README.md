# 크로스오버

여러 채팅의 캐릭터와 유저가 한 장면에서 만나는 크로스오버를 써 주는 SillyTavern 확장입니다.
같은 캐릭터 A가 B채팅·C채팅에 있으면 **B의 A와 유저, C의 A와 유저**가 각자의 기억을 가진 채 등장합니다.

- QR처럼 **주제만 자유롭게** 적으면 끝. 언어·분량·문체는 **지금 쓰는 프리셋**을 그대로 따름
- 채팅 2~3개 (1:1 채팅, 그룹 채팅 모두 가능)
- 채팅별 **페르소나 자동 감지**, **요약 자동 불러오기** (요약 확장이 꺼져 있어도 채팅 파일에서 읽음)
  - 코끼리를 생각하지마 · Memoria · 시나리오 자동요약 · 기본 Summarize · Qvink Memory
- **다인봇 지원**: 로어북의 인물 중 대화·요약에 나온 사람을 모두 넣음 (직접 선택 가능)
- 결과는 **지금 열린 채팅에 숨김 메시지**로 들어감: 번역·테마·정규식은 그대로, AI 맥락에는 안 들어감
- **형광펜**: 채팅마다 색이 하나씩. AI가 쓰면서 등장인물 이름을 직접 표시하기 때문에 이름만 칠해짐
- 다른 확장 없이 동작

## 설치

ST → 확장(블록 아이콘) → **Install extension** → 이 저장소 주소를 붙여넣기

## 사용법

1. 결과를 넣을 채팅을 엽니다.
2. 입력창 위 QR 바의 **크로스오버** 버튼을 누릅니다. (마법봉 메뉴에도 있어요)
3. 처음이면 오른쪽 위 **⚙** 를 눌러 크로스오버할 채팅을 고릅니다. 고른 구성은 **저장** 버튼으로 세트로 남길 수 있어요.
4. 보고 싶은 장면을 적고 **Ok** (Ctrl+Enter).

슬래시 명령:

```
/crossover 두 사람이 같은 카페에서 마주친다
/crossover set="세트 2" 비 오는 날
```

### 형광펜

- AI가 본문을 쓰면서 등장인물 이름을 `<w1>이름</w1>`처럼 감싸고, 확장이 그 표시를 지운 뒤 그 이름만 칠해요. (ST 정규식은 쓰지 않아요)
- 같은 표기가 두 채팅에 다 쓰이면 원문에서는 나온 순서대로 색을 맞추고, 번역문에서는 구분할 수 없으면 칠하지 않아요.
- 번역용으로 ST 화면 언어의 표기도 함께 받아서, 번역한 뒤에도 칠해져요.
- 채팅 카드 왼쪽의 동그란 색 칸으로 색을 바꿀 수 있어요.

## 프리셋 사용 방식

채팅 완성(Chat Completion) 프리셋의 켜진 프롬프트를 순서대로 쓰고, **Chat History 자리에 크로스오버 자료**를 넣어요.
캐릭터 카드·페르소나·월드인포 표식은 지금 열린 채팅의 것이 섞이지 않게 빼요.

## 저장 위치

- 설정·세트: `extensionSettings.crossover_episodes`
- 에피소드: 넣은 채팅의 숨김 메시지 (`extra.crossover_episode`에 형광펜 정보)
- 다른 채팅 파일은 **읽기만** 해요.

## 코드 구조

```
index.js         진입점 (QR 버튼, 마법봉 메뉴, 설정 패널, /crossover)
ui.js            주제 입력창 / 채팅 고르기 창
modal.js         테마와 무관한 자체 창
settings.js      작업 중인 구성과 저장된 세트
sources.js       캐릭터·그룹·채팅 파일·로어북 읽기 (캐시)
persona.js       채팅별 페르소나 판별
summaries.js     요약 확장 어댑터
lore.js          다인봇 로어북 인물 선택
prompt.js        세계별 자료 + 지시문 (모델이 읽는 문장은 영어)
preset.js        현재 프리셋에 자료 끼워 넣기
runner.js        생성 흐름
chat-insert.js   열린 채팅에 숨김 메시지로 넣기, 다시 그려지면 형광펜 다시 칠하기
highlight.js     AI 이름 태그 해석과 형광펜
dom.js, util.js  공용 도우미
```

## 보안

이 확장은 브라우저에서 JavaScript로 동작하며 모든 채팅 기록을 읽을 수 있습니다. 데이터를 외부로 보내지 않고, 생성은 ST에 연결된 API로만 합니다.
